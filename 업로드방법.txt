GitHub Pages 배포 파일 (v36 갤러리 유지)

1. GitHub 계정 로그인 → New repository → 이름 wedding-invitation, Public → Create repository.
2. 저장소의 Add file → Upload files를 누른 후, 이 폴더 안의 index.html, style.css, script.js, assets 폴더, .nojekyll 파일을 업로드합니다. ZIP 파일 자체를 업로드하지 마세요.
3. Commit changes를 누릅니다.
4. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save.
5. 공개 주소는 일반적으로 https://사용자아이디.github.io/wedding-invitation/ 입니다.

참고: 페이지에 포함된 신랑/신부, 가족 이름, 계좌번호 및 사진은 인터넷에 공개됩니다. 개인정보 공개 범위를 확인하세요.
